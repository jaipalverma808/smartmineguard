# 15. DETECTION ENGINE — NO AI
============================================================

The detection engine MUST NOT use:

- AI
- machine learning
- neural networks
- LLM
- external AI APIs

Use deterministic algorithms.

Implement these six detections:

-----------------------------------
1. WEIGHT ANOMALY
-----------------------------------

Compare:

permitted weight
vs
actual weighbridge weight

Example:

if actual_weight > permitted_weight:
    flag anomaly

Also compare against vehicle capacity where available.

-----------------------------------
2. ROUTE DEVIATION
-----------------------------------

Compare GPS route with permitted route/corridor.

Use PostGIS where possible.

Calculate:

- distance from permitted route
- deviation duration
- deviation distance

Flag when threshold is exceeded.

-----------------------------------
3. GPS BLACKOUT
-----------------------------------

Monitor GPS heartbeat.

If a truck stops sending GPS data unexpectedly:

flag GPS blackout.

Especially important when blackout occurs near suspicious
geographic areas/geofences.

-----------------------------------
4. PERMIT REUSE
-----------------------------------

A permit/e-Rawaana should not be reused after legitimate consumption.

Detect:

same permit
+
multiple trips
+
multiple vehicles
+
multiple timestamps

Flag suspicious reuse.

-----------------------------------
5. IMPOSSIBLE TRANSIT
-----------------------------------

Compare:

source
destination
legal/expected distance
timestamp
vehicle speed

If a trip would require impossible speed or impossible transit
duration, flag it.

Example:

distance = 300 km
time = 30 minutes

This should generate a suspicious event.

-----------------------------------
6. PRODUCTION-DISPATCH MISMATCH
-----------------------------------

Compare:

authorized production
actual production
total dispatched quantity
destination receipt

Detect unaccounted mineral quantity.

This is one of the most important features.

============================================================
# 16. PASS RECYCLING / SHORT LOOP DETECTION
============================================================

Implement deterministic pass recycling detection.

Compare:

permit creation time
loading time
weighbridge time
destination time
expected transit time

Also compare:

shortest legal route distance
maximum reasonable speed
actual trip duration

Flag suspicious short-looping or impossible reuse.
